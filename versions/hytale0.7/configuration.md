# Preview limits {#preview-limits}

These bounds are built into the current preview; there is no player configuration file yet.

| Limit | Current value |
| --- | --- |
| Active passengers | 1 per world |
| Registered tube parts | 128 per world |
| Parts in one journey | Up to 64 |
| Connections | Same builder for every part on a route |
| Chunk loading | Route chunks must already be loaded |
| Suction sound range | Up to 4 blocks |

Other players may use a completed route. Naming and dismantling belong to its builder. A real second-client session still needs verification.

Place sucker mouths two blocks above a solid landing. Allow room for a full-size player there and keep the actual bore clear. Ordinary blocks can surround a tube.

Shrinking takes about **0.85 seconds** before lift-off; growth takes about **0.7 seconds** at the destination. Normal movement is locked until growth finishes. Step at least **1.5 blocks clear** to re-arm an intake.

The sounds follow the actual intake, journey, arrival and crafting actions. Their final listening and comfort review is still open.
